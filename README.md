## Folder Hub 到底解决 Finder 的什么麻烦

Folder Hub 是藏在 MacBook 刘海下面的一块面板。鼠标移到刘海区域，面板滑出来；鼠标移开，它自己收回去。面板里装着若干个工作区，你可以把桌面做成一个工作区，下载目录一个，某个项目文件夹一个，鼠标悬停就能切换。

拿上传图片举例最能说清楚。你要把“项目 A”里的几张图传到浏览器里，正常流程是先切到 Finder，一层层点进项目 A，选中图片，再切回浏览器拖进去。用 Folder Hub 的话，鼠标移到刘海，悬停到项目 A，图直接拖进浏览器窗口。中间不用切换应用，也不用重新找一遍路径。

它对应的是三个具体麻烦。项目文件埋在三层子目录里，每次取一张图都要点进去；手滑关掉 Finder 窗口，路径全丢，得从头找；窗口明明开着，被浏览器盖住，还是看不见。Folder Hub 的面板浮在所有窗口之上，这三点它都能绕过去。

每个工作区有两种显示方式。Folders 模式只列出你选中的那几个文件和文件夹，看着干净；Subfolders 模式会把子目录的内容全部展开，适合文件层级不深的项目。多显示器和全屏应用下也能用，全屏时同样能从面板里选文件。

它不做的事得说清楚。Folder Hub 没有临时暂存区，不能把文件先丢进去放一会儿再处理。它只负责缩短找到并取出文件的路径，文件管理的全流程还得靠 Finder。
